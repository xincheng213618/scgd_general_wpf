# Hikrobot MVS managed binding

`MvCameraControl.Net.dll` is the unmodified x64 managed binding from Hikrobot MVS 4.3.2, `Development/DotNet/win64`, assembly version 4.3.2.2. Copyright belongs to Hikrobot; this file is not covered by ColorVision's source license.

Used by the isolated HK capture diagnostic window. Install the matching Hikrobot MVS runtime and camera driver separately; this assembly does not contain the native SDK or drivers. Do not replace the camera's installed runtime as part of running a benchmark.
