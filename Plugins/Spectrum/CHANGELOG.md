#   CHANGELOG

## [2.3.3.10] 2026.08.12

1. 将采集标定基础设施下沉到主程序 Spectrum 设备服务，插件聚焦独立应用的标定计算与结果校正，移除重复的功能扩展注册路径。
2. 新增结果数据校正窗口与插件侧校正计算器，使已采集光谱可按幅值标定文件重新计算并查看校正结果。

## [2.3.3.9] 2026.08.12

1. 删除客户端中未使用的许可证生成、私钥和签名逻辑，仅保留运行时所需的许可证解析与显示，避免发布包携带签发材料。

## [2.3.3.8] 2026.08.11

1. 新增主程序光谱仪扩展入口，可从设备页安全交接设备控制权并打开 Spectrum 幅值标定窗口。
2. 交接时同步通信参数、积分时间、平均次数和标定组，等待旧服务释放设备后再由插件直连，避免两个运行时并发占用光谱仪。

## [2.3.3.7] 2026.08.08

1. 统一主界面、Socket 与定时任务的设备操作和测量流程，避免并发访问原生句柄、校零数据和关闭中的设备。
2. 光谱结果只保存有效波长点并延迟生成曲线，限制可见结果数量，降低连续测量的内存、数据库和界面刷新开销。
3. 优化直连连续采集、统计和日志写入，修复关闭、更新与 Direct 会话之间的资源竞争。
4. 简化结果查询、删除、排序和绘图结构，并补充有效光谱范围自动化测试。

## [2.3.3.6] 2026.08.07

1. 实时日志面板改用 Spectrum 独立持久化配置，默认保留 1000 条并独立保存自动刷新和显示参数。
2. 窗口关闭时主动释放日志控件，避免重复打开或退出时残留日志 appender。
3. ColorVision 插件最低主程序版本更新为 `1.4.12.21`。

## [2.3.3.5] 2026.08.07

1. 修复自动校零前快门未连接时连续测量忙碌状态未复位，避免更新长期误判为设备占用。

2. 快门与滤色轮异步串口操作纳入更新安装门禁，设备通信期间不会退出覆盖程序文件。

3. 自动恢复备份后验证 robocopy 结果和关键运行文件；恢复失败时保留现场并禁止启动不完整程序。

## [2.3.3.4] 2026.08.07

1. 独立版新增软件内检查更新、完整 ZIP 下载进度与取消。

2. 更新包在安装前验证签名、SHA-256、ZIP 路径、CRC 和程序版本。

3. 退出后由临时 CMD 解压并覆盖当前用户可写目录；失败时恢复备份，成功后自动重启。

4. 插件版继续通过 ColorVision 的 CVXP 更新链路发布，不重复检查独立版更新。

## [2.1.7.0] 2026.03.30

1.重构项目架构，采用模块化设计：将 MainWindow 拆分为 Chart、Connection、Measurement、Export、ListView、Eqe 等部分类

2.新增 Configs 子目录：SpectrumConfig、CalibrationGroupConfig、CalibrationFileValidator、FilterWheelConfig、FilterWheelController、ShutterController、SmuConfig、SmuController

3.新增 Models 子目录：SpectralData、ViewResultSpectrum 数据模型独立管理

4.新增 View 子目录：ColorimetryHelper（CIE色度计算）、RaCalculator（显色指数Ra计算）、WavelengthToColor（波长转RGB）

5.新增 Layout 子目录：DockLayoutManager 实现 AvalonDock 面板布局持久化

6.新增 Data 子目录：ViewResultManager 数据库存储与管理，基于 SqlSugar ORM

7.新增 License 子目录：LicenseSync 实现本地与全局许可证双向同步

8.新增 Help 子目录：内置帮助文档系统，包含专业术语和使用指南

9.新增 Menus 子目录：SpectrumMenuIBase 菜单基类，LayoutMenuItems 布局菜单项

10.新增 Calibration 子目录：CalibrationGroupWindow、GenerateAmplitudeWindow 校正组管理界面

11.新增 PropertyEditor 子目录：TextSerialPortPropertiesEditor 串口属性编辑器

12.新增多语言支持：英语、法语、日语、韩语、繁体中文、俄语

13.新增 CalibrationFileValidator 校正文件二进制验证

14.优化 EQE（外量子效率）计算模块
