# CHANGELOG

## [1.5.1.5] 2026.09.03

1. 图卡生成与图片投影源码迁入主仓库，改用当前 UI 项目引用，保持独立插件交付和已有配置兼容

2. 修正共享依赖打包范围，排除宿主已提供的 OpenCV 运行时，保留图片投影私有依赖及资源，缩小插件包体积

3. 保留四象限线栅默认 2×2、按数量或像素排列，以及线宽、颜色和视场配置

## [1.5.1.4] 2026.09.01

1. 四象限线栅增加可配置行列，默认保持 2×2

2. 排列支持按行列数量或按单元格像素宽高生成，相邻单元格交替使用水平和垂直线栅

## [1.5.1.3] 2026.09.01

1. 新增“四象限线栅”图卡，默认参数可逐像素复现 640×480 样图

2. 支持调整线宽、线条颜色和间隔颜色

3. 支持按视场系数或像素尺寸设置居中视场，并可配置视场背景颜色

## [1.5.1.2] 2026.08.30

1. 增强Reset功能：添加用户默认配置层
   - 新增"保存默认"按钮，可将当前配置保存为用户默认值
   - Reset按钮现在先重置到用户默认值（如果存在），否则重置到类默认值
   - 属性编辑器添加"恢复出厂"按钮，可直接重置到类默认值
   - 用户默认值存储在 Documents/ColorVision/Pattern/UserDefaults/ 目录

2. 升级 ColorVision UI 依赖至 1.5.7.0，修复图案编辑器加载失败的问题

3. 主色、副色统一使用自定义属性编辑器，保留 R/G/B/W/K 快选，移除各图案重复的颜色编辑按钮

4. 隐藏颜色 Tag，并根据实际颜色自动生成模板命名标签，避免文件名与颜色不一致，兼容旧模板颜色读取

5. 修复副色选色器初始颜色错误的问题，取消或关闭选色窗口不再修改颜色配置

## [1.0.3.6] 2025.12.16

1.增加Reset按钮，重置所有参数

2.在有相同文件时，可以创建时间戳

3.修复MTF保存的bug

## [1.0.3.1] 2025.12.03

1.增加图片投影工具

## [1.0.2.1] 2025.11.24

2.增加噪点的图卡生成

## [1.0.1.20] 2025.11.11

1.增加按照像素视场生成图案的功能

## [1.0.1.15] 2025.09.10

2.MTF模板添加宝马图也斜矩形

3.增加搜索窗口

4.提供快捷打开方式

5.修复延迟加载的bug

6.更新README和CHANGELOG
