# Conoscope 架构知识入口

当前架构、运行契约和验证边界统一维护在[Conoscope 图像、采集与分析](../../../docs/04-api-reference/plugins/standard-plugins/conoscope.md)（`plugins.conoscope`）。

该主题覆盖 `ConoscopeCaptureWorkflow`、`ConoscopeDocument`、`ConoscopeViewState`、`ConoscopeImageHost`、配置/参考所有者和分析快照。

包内平台、依赖与操作风险见[模块 README](../README.md)。指向 `docs/` 的相对链接需要匹配版本的完整源码仓库；本地构建、设备运行和发布的授权边界互不替代。
