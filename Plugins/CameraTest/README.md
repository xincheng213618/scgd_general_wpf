# CameraTest 相机生产调试

用于相机生产调焦、参数记录和数据存档，提供独立 WPF 程序与宿主“工具 → 相机生产调试”入口。插件 ID 保持 CameraTest，支持从早期“相机出厂检测”版本升级。

## 使用

1. 从完整输出目录启动 `CameraTest.exe`，或通过宿主插件入口打开。可给独立 EXE 传入一个图像文件路径。
2. 打开图片，或配置现有相机 SDK 的型号、ID、BV_MODE/LV_MODE、位深、曝光、增益和 `sys.cfg` 路径后取图。
3. 使用图像下方矩形工具或“框选新增”，每框包含一个完整 BMW 靶标。画框自动加入左侧搜索区域，点击“开始分析”计算四边 RGB/Y SFR；移动或删除框后需重新分析。实时模式支持停止并冻结。
4. 在“存档信息”填写生产设备编号 / SN，可补充操作员、批次和备注；点击“记录并存档”，保存原图、参数、配置和同帧结果。没有分析结果时也可存档，记录会标记为未分析。
5. 点击“存档目录”查看记录；也可单独导出 JSON/CSV、保存图像和配置。

本地测试版提供“色差”“调焦趋势”“判定”页：显示 RGB 50% 边缘位移，记录最近 300 帧调焦曲线，按明确设置的阈值检查结果。判定阈值默认留空；调焦记录可单独导出，也随生产记录存档。当前在线首版为 1.0.0.1，不包含这些新增功能。

## 运行条件

- 需要 Windows x64/.NET 10 Desktop Runtime 及完整托管/native 依赖。`.cvxp` 复用匹配宿主的共享文件，不等于独立运行包。
- 不初始化数据库、MQTT 或后台服务。打开图片不访问硬件；连接、取图、实时和相机发现使用现有 SDK/驱动/许可证。
- 相机参数记录为当时请求 SDK 的设置，未经硬件回读确认。导入图片的拍摄参数未知，不会写成当前相机参数。
- 不提供跨设备自动比对。未知编码、无效通道、质量警告或缺失指标不能判为合格；阈值需要按实际产品规格设置。通道位移不是 ΔE 或纯镜头径向色差；不宣称 ISO 或 Imatest 数值一致性。
- BMW 当前适用于完整、近水平/竖直的靶标，严重透视、遮挡或过小靶标可能不可测。现场相机取流与重复性仍需验证。

构建：`dotnet build .\Plugins\CameraTest\CameraTest.csproj -c Release -p:Platform=x64`。详细参数、坐标/存档契约和验证方法见匹配源码仓库中的[相机生产调试](../../docs/04-api-reference/plugins/standard-plugins/camera-test.md)。包内不附带完整文档站点。

独立测试包：在仓库根目录执行 `pwsh -NoProfile -File .\Scripts\package_camera_test.ps1`。输出到 `Release/CameraTest/`，文件名包含四段版本、`test-win-x64` 和打包时间；仅供手动分发，不上传或配置在线更新，不附带 .NET。包内包含单一启动入口、必要依赖、使用说明和含文件哈希的版本信息；不会带入本机配置、日志或存档。详细打包约束见上方主题。
