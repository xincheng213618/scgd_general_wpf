# 1.0.0.6（本地测试包）

- 通道勾选同步筛选 SFR 曲线和结果列表，切换时保留当前点位及刃边。
- 修复拖动测量框时的异常和多选丢失，完善结果行选中反馈。
- POI 模板支持本地保存、编辑和管理，工具栏仅在内容放不下时显示展开按钮。

# 1.0.0.5（本地测试包）

- 图像标注支持 MTF50、MTF10、指定频率 MTF 与 MTF@0.5，并用虚线显示实际刃边。
- 四边测量框的大小、距靶标中心距离可配置，应用后自动重新分析。
- 色差页显示有效组数、缺测说明及中文原因，选中测量框时同步对应通道位移。

# 1.0.0.4（本地测试包）

- 精简界面，增加菜单栏，图片信息统一到状态栏；相机可直接选择并调节曝光、增益。
- BMW 标注与图像控件保持一致，默认显示 MTF50，字号固定且可调，支持选中小框后右键单边 SFR。
- 视频支持预览、基础清晰度与 BMW 四边实时分析，沿用最新帧处理方式。
# 1.0.0.3（本地测试包）

- 修复使用矩形工具画框后无法开始分析的问题，画框自动加入 BMW 搜索区域。
- 移动、删除、撤销和加载搜索框时同步更新，修改区域后清除旧结果。

# 1.0.0.2（本地测试包）

- 增加 RGB 通道边缘位移和可选判定标准，保留不可测原因。
- 增加实时调焦趋势、窗口峰值及调焦记录导出，并纳入生产存档。
