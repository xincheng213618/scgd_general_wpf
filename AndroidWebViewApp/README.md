# XC WebView Android App

一个最小原生 Android WebView 应用，启动后打开：

`http://xc213618.ddns.me:9998/`

## 构建方式

1. 用 Android Studio 打开 `AndroidWebViewApp` 目录。
2. 等待 Gradle 同步完成。
3. 点击 Run 安装到手机，或执行 `Build > Build Bundle(s) / APK(s) > Build APK(s)`。

因为目标地址是 `http://`，项目已经配置：

- `android.permission.INTERNET`
- `android.permission.CAMERA`，用于扫码连接和 WebView 页面的视频采集请求
- `android.hardware.camera` 标记为非必需，拒绝权限后仍可手动输入地址
- `android:usesCleartextTraffic="true"`
- `network_security_config.xml` 允许 `xc213618.ddns.me` 明文 HTTP 访问

音乐播放使用系统文件选择器授权单个音频文件，不申请存储权限或整盘媒体库权限；播放器底层使用 AndroidX Media3/ExoPlayer，优先兼容 mp3、m4a、flac 等常见音频格式。

现场运维通道使用电脑端短时二维码配对、HTTPS 证书固定和手机设备密钥签名。已配对手机可以读取脱敏状态、性能与告警、显示或最小化主窗口，并提交需要手机明确确认和电脑本机共签的诊断、主窗口快照或服务维护作业。Android 2.5 起不再调用系统指纹或锁屏凭据门禁。

Android 2.6 增加只读进程性能快照：短采样 ColorVision 的 CPU，并显示工作集、私有内存、托管堆、线程、句柄、GC 次数和主 UI 响应延迟。接口不返回进程 ID、名称、路径、命令行、主机名、用户名、网络地址、窗口内容或业务数据；单次读数只用于定位当前异常，不当作长期趋势。

Android 2.7 增加“近期远程操作记录”：手机最多读取最近 30 条去标识审计摘要，用于确认作业申请、手机批准、电脑共签、窗口控制、性能读取和证据下载等动作是否实际发生。记录不返回设备 ID、人员名称、目标 ID 或内部关联 ID，也不用于识别具体人员。

Android 2.8 增加“当前检测状态”：手机可区分流程未运行、准备中、执行中和收尾中，并显示本次用时、按历史耗时估算的进度以及最近一次完成、失败、取消或超时结果。接口只读，不返回流程名、模板 ID、批次号、节点名、参数、结果文本或检测数据；进度长期不变化也不会被单独判定为卡死。

Android 2.9 增加“持续观察”：仅在该页面位于前台时，每 10 秒读取一次聚合流程阶段、进程 CPU/工作集、主界面响应和近期告警计数；退到后台立即停止，服务器不保存采样历史。观察接口不返回日志正文或任何流程、进程、主机、用户和检测身份数据，并将同一设备的高频读取审计按 5 分钟窗口合并，避免持续写盘和淹没近期操作记录。

Android 2.10 在持续观察页面内存中保留最近 30 个聚合样本，显示 CPU 均值/峰值、工作集范围、主界面最大延迟与慢/超时次数、检测阶段切换次数以及告警计数变化，并可通过系统分享面板发送脱敏趋势。离开观察页面会立即清空这批样本，不写本地文件或服务器历史。

Android 2.11 在持续观察中增加“取消当前检测”：只有电脑端确认主工作区处于活动执行生命周期时按钮才可用。手机明确确认后，应用会创建一次性无参数取消意图并立即完成移动审批，电脑端再通过现有 `ViewFlow` 执行会话请求取消；不会选择或启动流程，不接收流程、模板、批次、节点或参数，也不要求电脑旁再次共签。请求结果进入安全作业时间线和去标识审计。

Android 2.12 增加“检测设备在线概览”：从电脑端设备注册表读取固定类别的设备总数、在线数和离线数，并接入远程排障中心与持续观察。接口不返回设备名称、编号、标识、地址、MQTT Topic、配置、原始心跳时间或测量数据，也不提供设备重连、重启或任意目标选择。

Android 2.4 支持一次性主窗口安全快照：电脑端只渲染 ColorVision 主窗口并压缩为不超过 1.5 MiB 的 JPEG，不捕获整个桌面；快照在共签后仅保留 5 分钟，只能由申请设备读取一次，成功读取后立即从电脑端删除。手机先在应用内预览，只有用户再次点击分享才会把缓存副本交给其他应用。

“连接自检”会依次检查手机网络、主机解析、TCP 安全端口、TLS 证书固定、设备签名和电脑时间，并只展示不含密钥、证书指纹、设备 ID、用户名或机器名的调试摘要。临时断线不会要求用户删除配对资料。

“近期日志摘要”只读取固定大小的最新日志尾部，返回分级计数、来源分类和最多 12 条脱敏异常事件；不会返回日志文件名、路径或完整原始日志。手机可以通过系统分享面板转发同一份安全诊断摘要。

“远程排障中心”把脱敏事件、主窗口状态和待处理作业汇总成固定建议。Android 端只识别内置白名单动作：查看脱敏事件、显示主窗口、查看审批，以及申请重启 MQTT；未知动作不会显示。MQTT 重启建议只创建维护作业，仍需手机明确确认和电脑端本机共签，不接受服务名、命令或路径等远程下发参数。

“白名单服务健康”只显示 ColorVision 后台服务与 MQTT 消息服务的规范化运行状态，不返回服务账户、程序路径或启动参数。排障中心只有在 Windows 服务管理器确认本机 MQTT 已停止或暂停时才建议维护；旧日志本身不会触发重启建议。

“作业与审批”使用面向手机的安全摘要：显示固定目标、风险、四阶段时间线和证据类型，不返回申请设备、理由、输入参数或电脑端内部收据 ID。安全分享摘要会附带同一份白名单服务状态。

完成手机明确批准和电脑端本机共签后，发起作业的手机可在 24 小时内下载并分享安全诊断 ZIP。包内仅包含白名单运行状态、脱敏事件、规范化服务健康和去标识审计；不包含机器名、用户名、设备 ID、进程 ID、网络地址、凭据、原始日志、数据库、用户文档或图像。下载固定为 2 MiB 上限，响应与本机文件都会核对 SHA-256，其他已配对设备无法读取。

“引导支持会话”是最长 15 分钟的有限文本通道：会话只对发起它的已配对设备可见，必须先由电脑端本机同意，且只在激活且未过期时允许手机或 Web 中继交换消息。手机在等待本机同意时每 5 秒刷新，进入可输入状态后停止重建页面；单条现场消息最多 500 字。接口不会返回设备 ID、电脑账户、内部任务或审计标识，也不支持远程桌面、命令或任意文件。
