# 文本编辑器

解决方案文件标签和 `AvalonEditWindow` 共用 `AvalonEditControll`，底层为 AvalonEdit。编辑器提供代码阅读、输入辅助、文档导航、查找替换和 Python 运行入口。补全与声明定位基于当前文档的词语和语法规则，JSON 提供解析错误定位；这些能力不包含跨文件类型推断、编译诊断、语义重构或调试器。

文件身份、外部变化、保存及关闭确认由[文档生命周期](./editor-document-lifecycle.md)定义，Python/F5 的磁盘保存和终端进程责任见[终端契约](../../01-user-guide/interface/terminal.md)。

## 代码地图与定位

右侧默认显示代码地图，覆盖整份文档的逻辑行。底图保留代码颜色与缩进，半透明区域表示正文可视范围，横线表示编辑光标位置。

- 点击地图滚动到目标附近；拖动可视范围平移正文，保留光标和选区，不改变文本或脏状态。
- 悬停约 350 ms 显示目标附近的只读代码预览，预览与正文共用文档及主题颜色，使用独立视图，不改变正文位置。
- 自动换行时通过 AvalonEdit 的行排版与滚动接口定位，不能直接用逻辑行号乘默认行高计算滚动偏移。地图保留折叠区域的文档占位，定位到已折叠区域时遵循正文折叠显示；跳转到行会移动光标并由编辑器显示目标位置。
- 工具栏可关闭地图，恢复普通垂直滚动条；设置中可调整地图宽度和悬停预览。
- 查找结果以右侧琥珀色短线显示，JSON 解析错误以红线显示；密集匹配按屏幕像素合并绘制。

地图底图与可视范围分开绘制。文档或主题、地图尺寸变化才重建底图，单纯滚动只重画范围与光标标记。底图按屏幕像素高度限制采样行数、每行最多取 180 个字符，通过后台优先级 Dispatcher 分批绘制；这是文档概览，不保证超长文档中的每个字符都出现在缩略图中。超过 2,000,000 字符时地图保留结构和导航，跳过额外的语法高亮扫描。

## 字体与显示设置

齿轮打开通用属性编辑器，`EditorPreferences` 接入现有 `IConfig` 配置服务；活动编辑器使用同一份设置，并通过弱属性事件更新显示。字体、字号、缩进、换行、地图和空白字符显示可持久化；通过现有 `ConfigHandler.TrySave` 保存失败时提示错误。未接入配置服务的独立宿主只使用内存设置。

默认使用 Cascadia Mono，回退 Consolas 与 Microsoft YaHei UI，字号 14 DIP，语法关键词保持正常字重；可切换 Consolas/Cascadia Code 或启用语法关键词加粗。字体未安装时遵循 WPF 字体回退，不自动下载字体。正文、地图与预览使用同一套主题语法颜色。

缩放支持 Ctrl+滚轮、Ctrl+加号/减号、底部百分比菜单，Ctrl+0 恢复 100%。缩放范围为 50%–250%，仅属于当前控件会话，不改已保存的基础字号。缩进参考线按可见行绘制。状态栏显示行列、缩进方式、编码与实际换行格式；同时包含不同换行符时显示“混合”。

## 查找、替换与编辑操作

| 操作 | 入口 |
| --- | --- |
| 查找 / 替换 | Ctrl+F / Ctrl+H，工具栏或正文右键菜单 |
| 下一个 / 上一个匹配 | F3 / Shift+F3；查找框内 Enter / Shift+Enter |
| 关闭查找 | 查找框内 Esc，或关闭按钮 |
| 跳转行与列 | Ctrl+G，输入 `行` 或 `行:列`；Enter 确认、Esc 取消 |
| 切换行注释 | Ctrl+/ 或右键；Python/PowerShell 等使用 `#`，C#/JavaScript 等使用 `//`，SQL 使用 `--` |
| 复制当前行或选区 | Ctrl+D |
| 上移 / 下移当前行或选中行 | Alt+上 / 下 |
| 折叠全部 / 展开全部 | 正文右键菜单 |
| 格式化 JSON | JSON 模式的正文右键菜单；可撤销 |
| 显示补全 | Ctrl+Space；输入两个标识符字符后自动触发 |
| 文档符号 | Ctrl+F12 / Ctrl+Shift+O，或工具栏 `{}`；搜索名称后 Enter 或双击跳转 |
| 文档内定义 | F12；同名声明不唯一时打开符号列表 |
| 返回 / 前进 | Alt+左 / 右，恢复行、符号、定义等跳转前后的位置 |
| 跳转匹配括号 | Ctrl+]；使用当前版本的括号配对结果 |

查找支持大小写、全字和正则，变化后合并刷新。正则匹配有 150 ms 超时，匹配数量上限为 20,000；正则无效、超时或超过上限时清空结果并禁用替换，不能对截断结果执行“全部替换”。普通替换按字面文本处理，正则替换支持 `$1` 等分组。替换前生成完整替换计划，再从末尾应用，一次全部替换对应一个撤销组。

磁盘文件加载保持原始文本，不因打开 JSON 就自动格式化。`SetJsonText` 仍为属性/结果 JSON 宿主提供格式化视图，`GetJsonText` 保留其既有 JSON 取值契约。文件编码沿用 AvalonEdit 检测与保存逻辑；未保存标记跟随撤销栈原始位置，撤销回已保存状态会清除脏标记。

## 输入辅助与文档分析

括号和引号默认自动配对，可包围普通选区。输入已自动生成的结束符会越过它；空配对可用 Backspace 一起删除，在括号内部 Enter 会产生带缩进的内层空行。配对避开注释、字符串及多字符输入，Python 同时处理常见字符串前缀和三引号。匹配括号显示轮廓高亮。自动配对、自动补全与括号高亮均可在编辑器设置中关闭。

补全列表包含所支持语言的关键词、当前文档词语与声明，以及 Python/C#/JavaScript 的常用代码片段。使用 Tab、Enter 或双击接受，标点只关闭列表；代码片段的参数占位符可继续用 Tab 切换。一次补全插入作为一个撤销组，补全过程先固定原始替换范围，避免文档锚点随插入移动导致光标越界。此补全不会解析外部模块、推断对象成员或连接语言服务器。

符号列表识别 Python 类与函数、C#/C++/Java 的类型与常见方法声明，以及 JavaScript/PHP 命名函数等文档声明。它依赖排除字符串、注释后的轻量语法规则；不保证覆盖所有语言结构或正确区分同名声明的作用域。定义跳转在后台分析完成后再次检查文档版本和光标位置，防止过期结果改变用户新位置。跳转历史使用文档锚点跟随编辑，重新加载文件时清空。

JSON 模式解析当前文本，首个解析错误显示正文红色波浪线、地图红线和底部行列提示，点击提示可跳转。文本变化立即隐藏旧错误，后台新结果只有在文档版本一致时才能显示；语法修复后自动清除。该诊断不验证业务字段或 JSON Schema。

## 折叠、后台刷新与控件生命周期

Python 使用缩进块折叠，处理多行函数头，并避开字符串、注释中的伪结构；C#/C++/Java/JavaScript/PHP/JSON 使用语法高亮排除字符串和注释后的括号结构；XML 使用 AvalonEdit XML 策略。它们是辅助导航规则，不是完整语言解析器，Python 缩进在代码块冒号后增加一级。

正文变化后延迟约 300 ms 合并分析更新。折叠、文档词语、声明和括号配对共用后台语法扫描；计算基于不可变文本快照，在后台创建独立文档，完成后仅在原文档版本仍一致且请求未取消时应用结果。输入补全可继续使用上一轮词语候选，但符号跳转、括号高亮和诊断只使用当前版本结果。新编辑、隐藏、卸载或释放会取消过期工作。

超过 2,000,000 字符时暂停折叠及代码分析；词语上限为 20,000，声明上限为 4,000，补全列表最多显示 200 项。声明识别跳过超过 2,000 字符的单行。它们限制辅助功能成本，不截断、改写或阻止保存正文。

`Unloaded` 或不可见时停止刷新，关闭预览与补全窗口并解除全局主题订阅；重新显示时恢复当前文档。这与最终 `Dispose` 不同，不能将停靠期间的暂时卸载当作销毁。`Dispose` 取消计算并移除文档、输入辅助、主题、搜索、地图等资源。工作区和独立编辑器窗口在真正关闭时仍应调用它。

## 验证

`ProfessionalEditorTests` 覆盖 Python 多行头/文档字符串和括号折叠、注释选区边界、整行移动及复制的换行与撤销、搜索模式和替换上限、JSON 原文与撤销清脏、真实 WPF 地图滚动/换行定位、预览不改变选区、隐藏后恢复及查找栏全部替换。输入用例覆盖自动配对、成对删除、三引号、换行缩进、片段占位符、实际补全窗口的插入与撤销；集成用例通过共享控件的符号列表和 JSON 错误提示验证定位。长文件用例覆盖 10,000 行与 100,000 行文档的地图定位、编辑刷新和撤销。`AvalonEditorSupportTests` 覆盖已有语法颜色、编码保存、撤销重做和脚本命令契约。

在真实窗口补充检查明暗主题、字体、缩放、地图拖动、悬停预览、查找与跳转输入焦点，以及长文件输入响应。局部测试或编译不等于完整主程序、真实 Python 环境或所有语言语义已验证。
