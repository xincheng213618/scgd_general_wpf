# Web 历史性能基线

本页保留原 `Web/PERFORMANCE_AUDIT.md` 中可用于比较的历史测量。原记录以 **2026-07-18** 为基线日期，并包含明确标注 **2026-08-12** 的补充项；其他补充样本没有独立日期，不能统一当成同一天或当前版本的结果。

这些数字来自当时的记录，本页整理未重新运行基准。原记录没有为每个样本固定提交、完整硬件/运行时信息和原始测量附件，复现时应重新记录这些条件。当前接口、性能预算与剩余演进方向见[Web 架构](../../03-architecture/components/web.md)，线上指标含义见[访问及性能观测](./observability.md)。

## 基线方法

- 后端使用当时真实的 `H:\ColorVision` 制品树与事务一致的临时 `marketplace.db` 副本。
- 基准进程关闭访问统计。接口各预热两次，再通过 Flask test client 测量 15 次。
- 前端大小来自生产 Vite 构建及其 preload 图；标为 gzip 的值是压缩字节量。
- 原记录说明基准请求没有重写生产索引或访问统计数据库。以下另有标注“预检”“模拟”或“进程内比较”的样本，不应当作网络请求实测。

## 公共响应比较

表中的 Legacy 与 Compact 是当时比较的两种表示，不说明当前默认接口已删除旧表示。

| 接口样本 | Legacy 字节 | Compact 字节 | Legacy 中位耗时 | Compact 中位耗时 | Compact p95 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Home | 2,933,265 | 14,064 | 43.93 ms | 19.36 ms | 21.15 ms |
| Releases | 5,759,893 | 74,707 | 45.23 ms | 19.92 ms | 21.29 ms |
| Changelog | 1,165,048 | 200,460 | 41.45 ms | 6.33 ms | 10.43 ms |

原始响应体积分别减少约 99.5%、98.7%、82.8%。这些结果对应上述目录与请求样本，不是任意数据规模的上界。当前 compact、SQL 分页及文件回退的范围见[公共读模型](./public-data.md)。

| 补充样本 | 记录结果 | 范围 |
| --- | --- | --- |
| 模拟 5,000 个 APK 的目录 | 每次 compact 响应小于 64 KiB | 合成目录样本，Windows/Android 分页各自计算 |
| 2026-08-12 changelog：381 个发行项，首 20 项 | 原始字节 156,526 → 10,110（约 93.5%）；gzip 52,250 → 4,848 | 显式分页的首屏响应，不是完整 changelog |

## 前端与存储工作量

| 样本 | 记录结果 | 方法或限制 |
| --- | --- | --- |
| 公共入口 module-preload JavaScript | 约 681.8 → 233.5 KiB gzip，减少约 65.8% | 当时的生产构建图；管理页及 Pro Components 等使用路由 chunk |
| 首页装饰视频 | 2.34 MiB | 当时采用 window load 后的空闲加载机会，reduced-motion/data-saving 情况不请求；不是所有浏览器加载链路实测 |
| ProForm 管理页 chunk | 506.16 KiB minified | 原记录未标 gzip；这是懒加载管理 chunk，不计入上述公共 preload 样本 |
| 发行变更签名 | 原路径 3.7–4.5 s；元数据签名 10 次读取中位 29.52 ms，最小 27.64 ms，最大 131.26 ms | 当时的历史目录；记录仍可检测同名文件覆盖 |
| 插件包哈希 | 63.2 MiB 文件约 381.9 ms | 用于说明将哈希从 GET 关键路径转到索引刷新工作的收益；当前回退边界另见[插件索引](./plugin-catalog.md) |
| API key 使用时间合并写 | 同一分钟 20 次校验仅写 1 次；50 次比较中，强制写路径 50 次更新/提交共 3.38 s，合并路径 1 次共 3.22 s | 密钥验证 CPU 成本仍占主要部分，减少的是 SQLite 写锁/WAL 工作量 |
| 32 MiB 流式交付 | 原 `send_file` 中位 8.29 ms，共用交付层 7.65 ms；字节一致且未整文件缓冲 | 本地进程内，每条路径预热 1 次、测量 5 次；不是端到端网络吞吐基准 |

不同表中的 warm/cold、gzip/minified、进程内/网络口径不能混用。当前管理首页静态模块预算由构建脚本执行，见[性能预算](../../03-architecture/components/web.md#性能预算与现有检查)。
