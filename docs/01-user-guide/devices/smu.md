# SMU 参数、结果与输出关闭

`DeviceSMU` 的手动点测、手动扫描和 Flow 节点有不同的参数来源与完成处理。查询“通道串了”“扫描不使用当前值”“失败后是否关闭输出”时，必须先区分这三条调用路径。

点测和扫描会向被测件施加电压/电流。执行前由现场操作者确认接线、极性、限压/限流、额定范围与授权。客户端限制开关或成功回包不能替代仪器保护；只读问答、文档或代码修改不授权通电、扫描或试验保护动作。

## 哪一层拥有参数

- `ConfigSMU` 拥有设备类型、设备名和连接等设备配置，设置提交走公共[设备配置保存](./configuration.md)；保存不等于远端已经应用。
- `DisplaySMUConfig` 由 `DisplayConfigManager` 按设备 `Config.Code` 管理。A/B 通道分别持有电压源、电流源的测量值/限值以及显示读数；`CurrentSourceConfig` 由当前 `Channel` 和 `IsSourceV` 选出。切换通道或源类型是在切换参数组，不是发送测量命令。
- `TemplateSMUParam` / `SMUParam` 是数据库模板参数，模板字典 ID 为 `13`。手动扫描读取模板的源类型、起点、终点、点数与限值，但通道显式取自提交时的 `DisplayConfig.Channel`，不是 `SMUParam.Channel`。服务模式载荷保持原有字段，本地模式还使用模板的 `IsAutoRng` / `SrcRng` / `LmtRng`。
- Flow 节点使用节点/服务模板自己的参数，不继承手动控件选择；量程、通道与关闭输出设置须按具体节点核对。

显示配置中的值可能来自之前输入或之前读回，不能作为当前仪器输出状态的证据。

## 本地源表的连接与执行

设备的齿轮设置按钮打开单页源表配置窗口，同页编辑 `ConfigSMU` 的设备连接/测量设置，以及 `DisplaySMUConfig` 的本地源表、波特率、限值检查、源类型和手动通道。在这里启用“使用本地源表”，由当前 ColorVision 电脑直接连接。串口模式（`IsNet=false`）显示串口选择，本地模式下还显示波特率；网口模式（`IsNet=true`）显示 IP。已有网口地址保持原值，未配置时 IP 输入框初始值为 `192.168.100.100`；IP 使用共享的四段 IPv4 编辑器，每段范围为 0～255，可粘贴完整地址；点击 IP 旁的“编辑”进入输入状态，点击行内“确定”或按 Enter 结束地址编辑，窗口“确定”才保存配置。窗口内切换模式会保留两边的输入，只有确认时才把所选模式的地址写入原有 `ConfigSMU.DevName`；取消不修改两个实际配置对象。持久化与服务解析继续使用 `IsNet + DevName`，不增加另一份地址字段，手动连接和原有本地 Flow 节点读取同一套配置。网口地址须为 IPv4，不含协议或端口；Keithley/Precise 串口须为 COM1～COM256。

源表设备面板左侧并排显示紧凑“打开/关闭”按钮与齿轮设置图标，点击齿轮可直接进入配置窗口，该入口与属性窗口中的“修改配置”均不要求管理员权限；按钮上方不显示仪器标识行或预留空行。“测量设置”显示四线制、前面板端子与毫秒单位的 `DelayTime`。`IsSrcA` 作为兼容字段保留，手动测量与流程仍分别使用显示配置和节点的通道参数。

`Keithley_2400` / `Keithley_2600` 网口连接使用 TCP Raw Socket，端口固定为 5025。IP 地址只填写如 `192.168.1.100` 的仪器地址，不含协议、端口或 VISA 资源串；当前执行连接的电脑须能访问该地址。2450 使用 `Keithley_2400` 驱动时，仪器端须在 `MENU → System → Settings → Command Set` 选择 `SCPI 2400` 并确认重启；LAN 地址在 `MENU → System → Communication → LAN` 查看或配置。2604 使用 `Keithley_2600`。以上为代码路径及[2450 官方手册](https://download.tek.com/manual/2450-900-01E_Aug_2019_User.pdf)说明，真机连接和命令兼容性仍需现场验证。

源表配置窗口设置的“本地串口波特率”仍归 `DisplaySMUConfig.LocalBaudRate`，默认 9600；Keithley 2600/2604 支持标准波特率到 115200，2400 到 57600，其它驱动目前只支持默认值。仅本地串口连接使用此参数，必须与仪器端波特率一致；网络连接忽略它，服务模式不发送此设置。旧显示配置缺少该字段时保留 9600。“使用本地源表”默认开启；新配置及缺少 `UseLocalSmu` 字段的旧配置使用本地，已明确保存的开启或关闭值继续保留，用户可手动关闭以使用服务模式。模式选择保存在显示配置中，连接占用期间保持当前后端，关闭后才能切换。地址、驱动类型、连接方式、串口波特率及接线/端子配置改变后，下一次本地“连接”、普通测量或高级执行会在会话锁内自动关闭旧输出与连接，再按本次参数尝试连接一次；确认成功后才执行测量。设备默认“测量延时（ms）”在下一次普通点测或扫描时按本次快照下发，无需重连。节点的独立延时仍优先，高级操作使用窗口自己的延时；修改保存值不会干预已在执行中的原生调用。

自动重连前先校验请求并检查目标端点占用；切换期间保留目标端点及整个流程的使用权，其他手动操作不能抢占。旧输出或连接释放失败时停止重连，按未知状态和端点隔离规则处理；新连接失败时返回本次诊断，不循环尝试，也不恢复旧输出。测量或脉冲执行失败后不会自动重放该操作。读取旧结果不为配置变化重连，因为重连会清除原生读数；应先执行新测量再读取。“关闭输出”始终关闭当前已有句柄，不为应用新连接设置而打开设备。

源表连接失败时，窗口和命令记录显示本次设备类型、连接地址、串口波特率及失败阶段；支持诊断的新驱动进一步区分串口打开/配置/读写失败、无响应超时、仪器错误提示和响应格式异常，并保留驱动原始详情。手动窗口的状态文本支持选择复制，长错误可滚动查看，失败也写入应用日志以供反馈收集。仪器返回 `TSP?` 表示错误队列非空，作为完整错误响应处理，不能当作成功或空响应超时。连接初始化沿用先清理错误再启用提示的引导命令，半行输入导致错误提示时最多重发一次；随后独立校验复位命令，不依赖自定义回显标记，也不按厂商或固定型号文字拒绝连接。型号由连接后的既有读取路径取得并展示，用于选择已确认支持的能力；未知型号提示高级功能不可用，通信和命令失败仍释放串口；核对仪器端设置并改回匹配的波特率后可再次连接。释放失败仍遵循未知状态与端点占用保护，不能跳过清理强行重开。

两个配置类及存储职责保持不变：确认时先将显示偏好写入本机 `DisplayConfigManager` 配置，再通过现有设备保存链路写入设备资源（服务器资源使用 MySQL，本地资源使用本地配置库）。服务仍读取原设备配置；本地源表与波特率不迁入设备数据库字段。显示偏好先保存，使设备数据库保存失败时仍保留本机设置；两个存储之间没有跨库原子事务。提交只更新显示配置中的可编辑偏好，保留当前读数和 A/B 通道的测量值/限值对象。

`LocalSmuNative` 使用随应用交付的 x64 `cvCamera.dll` 源表导出和既有 `PassSx` 绑定。优先通过 `cvPss_Sx_OpenNetDeviceWithError` 传递连接设置并取得本次失败分类和诊断；缺少该导出的旧 DLL 沿用原打开路径，非默认串口波特率通过 `cvPss_Sx_OpenNetDeviceEx` 传到驱动，缺少 Ex 时明确提示更新，不静默退回 9600。打开后读取仪器标识；“点亮”调用普通测量，“设置”调用步进测量。每次操作先选择提交时的 A/B 通道和源类型，手动扫描在同一次串行操作内关闭该通道输出，成功确认关闭后才完成命令。所有 SDK 调用在后台执行，同一连接按顺序执行；不会用延迟后台任务关闭后续测量的输出。

源表配置的“测量设置”提供本地“积分时间（NPLC）”，随设备配置保存，仅支持 `Keithley_2400` 和 TSP `Keithley_2600` 普通采集路径；服务模式隐藏此项，不改服务协议。打开本地连接时下发采样积分，不开启输出；已连接时修改值，在下一次普通点测、扫描或流程采集中应用，无需重连，读取旧结果不改变其采样设置。旧配置保持 2400 的 0.01 和 TSP 驱动的 1，2400 支持 0.01～10，TSP 支持 0.001～10。2651A/2657A 的普通 NPLC 复用 `Keithley_2600` 驱动，选择积分 ADC，避免高速 ADC 忽略积分时间；这不扩大原有客户端电气限制、扫描优化能力或高级型号范围。高级窗口仍使用独立 NPLC，返回普通采集后恢复设备设置。非默认值要求提供 `cvPss_Sx_SetNPLC` 的配套 DLL，旧 DLL 缺少接口时明确提示更新；原默认值沿用旧行为。

参数中的电流源值和限流值使用 mA，进入 SDK 时转换为 A；电压使用 V。会话内部点测/读取/扫描电流统一为 mA。为兼容既有结果表、视图和消息，点测结果 `I` / `SMUResultModel.IResult` 保持 mA，扫描 `IList` / `SmuScanModel.IResult` 保持 A，电流源扫描的 `ScanList` 也使用 A。手动量程参数按既有 SDK/服务约定直接传递，不做源值单位转换。旧服务 `GetMeasureResult` 的电流换算与点测不一致，本地读取按 SDK 的 A 转 mA；真机读取单位仍需单独核对。

结果视图按所选记录切换：单点显示 V、I、R、P 和测量记录；至少两个点的扫描展开 I–V 曲线和逐点表，选点联动读数与曲线标记。默认横轴 V、纵轴 mA，可交换横纵轴；“纵轴 log10”按当前纵轴量显示对数刻度，仅绘制正有限值，零、负数和无效值形成断点，不取绝对值，原始表格和导出不变。曲线保留采集顺序和回扫路径，不连接独立点测；Ctrl 多选扫描可叠加。脉冲曲线不表示完整时域波形。选择历史记录关闭“跟随最新”，重新启用切回最新；清空列表只移除视图数据。

读数卡自动使用 mV、µA、nA、MΩ 等工程单位；逐点表、历史表和 CSV 使用 V、mA、Ω、W，CSV 保留完整数值精度。电阻优先使用仪器原生电阻结果，否则按当前工作点 V/I 计算，不能当作微分电阻。点测的“源设置”读取 `src_value`，保护限值读取 `limit_value`；扫描范围读取 `src_begin` / `src_end`。未记录的保护限值显示说明，不将扫描终点误作保护值。

记录和详情中的“用时 (ms)”沿用点测、扫描结果表的 `total_time` 字段；本地实时结果、服务端入库结果和历史查询共用这一映射。空值显示“—”，已有的 0 值保留为 0。普通本地操作统计测量、读取或整批扫描的 SDK 调用区间；高级操作统计整次高级 SDK 调用。耗时包含该调用内的通讯、配置和等待，不包含排队、打开连接或结果入库；普通路径在测量后单独关闭输出的时间也不计入。扫描显示整批耗时，历史值按原存储值展示。`SmuResultViewTests` 验证点测/扫描切换、采样单位、历史选择与清空、扫描叠加和 CSV 原生电阻保留。

本地校验拒绝无效通道、非有限源值/限值、零限值、无效手动量程，以及不在 2～100000 范围内的扫描点数。启用 `IsUseLimitSigned` 时使用既有机型限值，并检查扫描两个端点的最大绝对值。失败通过 `MsgRecord` 返回，校验失败不会调用测量 SDK。

本地结果直接进入现有源表结果视图；已连接 MySQL 时使用现有结果表持久化，否则为内存结果，`MasterId=0`，不作为历史数据库记录。点测只更新结果所属通道，只有它仍为当前显示通道才同步 Spectrum 的 V/I；扫描不执行这一点测同步。数据库保存失败会报告命令失败，已采集的数据仍可供查看。

连接、输出和端点占用由 `LocalSmuSession` 持有。关闭/释放取消未开始的排队操作；已进入原生 SDK 的调用必须等其返回，随后关闭相关输出和连接，不能提前复用句柄或声明取消已完成。释放失败时状态为未知，并保留端点占用，避免另一会话立即重开；诊断和实机输出确认仍由现场操作承担。本应用内相同设备名/连接类型不能同时由多个本地会话占用，已观察到的服务占用也阻止切换；无法由此检测其它程序或另一台机器的连接。

设备右键菜单的“本地源表”和 `LocalSmuNode` 的同名命令打开独立的 `LocalSmuWindow`；打开窗口不连接或通电。窗口分别配置源类型、工作方式、测量量、扫描和波形，并提供连接、关闭输出、断开、停止、保存参数、应用到节点和 JSON 导出。节点入口编辑独立副本，点击“应用到节点”后才修改节点；高级设置以 `LocalSmuSettings.v1` 随流程保存。节点的“使用窗口设置”开启时，量程由窗口管理，隐藏旧量程字段；关闭该选项可恢复普通点测及重复框自动合批。没有高级设置键的旧节点继续原有执行路径。保存窗口参数归 `DisplaySMUConfig.LocalSettings`，不改变服务 MQTT 参数。

高级执行通过新原生导出 `cvPss_Sx_GetLocalFamily`、`cvPss_Sx_ExecuteLocal`、`cvPss_Sx_CloseLocalOutput`，需要匹配的新 `cvCamera.dll`。IDN 严格区分已识别的 2400、2430、原始 2600 和 2600 A/B；未知型号、其它驱动及缺少导出的旧 DLL 明确拒绝高级操作，不静默用普通点测替代。能力识别和协议替身不代表真机已验收，驱动分类名称也不等于仪器实际型号。

普通 `LocalSmuNode` 默认开启“沿用设备延时”，继续使用设备配置的“测量延时（ms）”，旧流程没有新增字段时保持这一行为。关闭该选项后显示节点自己的“测量延时 (ms)”，允许 0 和非负有限毫秒值，随流程保存并在本次节点执行时固定；它是输出设置后、源表采样前的等待，扫描合批时逐点应用，不在采样后再追加一次等待。在节点里已经等待灯响应时，下游无需再叠加同用途的延时；如果由下游延时节点统一等待，可以将此处设为 0，但该次源表 V/I 会在下游等待之前采集。节点设置不改设备默认值，下个沿用设备设置的节点和普通手动测量恢复设备默认延时；无需为节点覆盖值断开重连。开启“使用窗口设置”后隐藏这两个普通延时字段，改用窗口的高级测量延时。

2600 普通流程步进点测（包括旧 GetData 节点的本地执行路径）按连接和当前通道复用已确认的源类型、接线、延时和量程。首次配置在仪器运行内存定义测量函数，连续点只发送短调用及变化的源值/保护限值，保持一次命令往返；函数不保存到仪器非易失存储，数字使用可完整往返 double 的精度。源表采样、错误队列检查和旧读取命令使用的实测 V/I 全部保留，不通过降低 NPLC、关闭调零或改变采样精度提速。普通关闭输出确认成功后保留静态配置和函数，但忘记源值/保护限值，下次测量重新发送两者，兼容关闭状态对源值的影响；关闭失败则使缓存完全失效。切换通道或源模式、普通手动点亮、读取、扫描、高级操作、断开重连或测量失败后完整重新配置。设备返回错误、函数丢失、读数不完整或超时会使缓存失效，并尝试关闭当前通道。通过仪器面板或其它程序修改配置后应断开重连。反馈原生命令日志的 `txBytes` 是本次发送字节数，`txMs` 是发送阶段时间，`rxMs` 是发送完成到完整回包的等待时间；这些软件计时不能替代独立的电气稳定时间测量。

2600/2604 本地高级直流测量会复用同一连接、当前通道及源模式的配置，参数不变时不重复初始化；源值、保护值或采样参数变化时只下发差异。采样等配置变化时先关闭仍开启的输出，再更新参数；自动调零“一次”在配置时执行，配置不变的连续测量不重复调零。每点将输出设置、测量和可选的完成后关闭合并为一次通信往返，读数、保护状态及错误仍完整检查。切换通道/源模式、普通测量、脉冲、显式关闭输出、断开/重连或失败后重新配置。通过面板或其它程序修改仪器参数后应断开重连，避免继续复用旧配置；离线命令验证不承诺具体实机耗时。

| 输出与测量 | 电压源、电流源；输出并测量、仅输出、仅测量接法；保留实测 V/I，电阻 Ω 与功率 W 单独显示 |
| 电阻 | 2400 手动/自动电阻、直流偏置补偿、2/4 线及 Ohms Guard；2600 使用设定激励的 V/I 比值测量电阻。Ohms Guard 需要对应六线实物接线 |
| 扫描 | 线性、同号非零起止值的对数、任意列表；高级直流路径逐点执行；2400 源记忆扫描支持最多 100 个同源类型的源值及逐点保护限值，覆盖本次使用的源记忆槽 |
| 2600 A/B 脉冲 | 仪器定时器控制周期与脉宽，内部触发列表并采集双 V/I 缓冲及原始状态；结束返回基线。原始 2600 不启用这一 A/B 定时器协议 |
| 2400 脉冲 | 普通 2400 使用 Source Auto Clear 的 SDM 间接脉冲，脉宽/周期为目标值，采样位置由 SDM 与积分时间决定，实际波形必须示波器校准；2430 专用脉冲当前仅输出，脉宽 0.15～5 ms、关闭时间至少 1.1 ms，不宣称并发 V/I 测量 |
| 关闭状态 | Normal、HighImpedance、Zero，2400 另支持 Guard；“关闭输出”直接配置所选关闭状态再关闭目标通道，不为应用高阻状态而先通电 |
| 采样与触发 | 源/测量量程、NPLC、稳定延时、平均滤波、自动调零、2600 A/B 高电容模式；立即或外部触发。2400 Trigger Link 1～4 逐点触发；2600 数字 I/O 1～14 直流逐点、脉冲整组起始触发 |

这里的 Ω 是直流电阻；HighImpedance 是关闭后的高阻状态；高电容模式用于驱动电容负载稳定。这些功能均不表示交流阻抗、频率/相位或电容量测量。高电容模式的电流保护不得低于 1 µA，避免仪器隐式提高保护限值。脉冲要求固定源/测量量程，关闭滤波、自动调零及高电容模式；V/I 积分窗口必须位于脉宽内，脉冲组最短时长须小于操作超时。客户端电压、电流限制仍沿用已有保守门限，不因此开放仪器扩展脉冲功率区。

2600 电阻测量先按测试源值和保护限值施加激励，再使用同次实测 V/I 计算 Ω，例如 1 V / 1 mA = 1000 Ω；电流为零、比值溢出或无效时显示为空。对于 LED 等非线性器件，它表示该工作点的静态比值，随激励变化，不是微分电阻。2400 使用仪器返回的原生 Ω，可选择手动激励、自动电阻或直流偏置补偿；自动电阻时测试电流由仪器按电阻量程选择，界面源值不控制激励。窗口的“电阻量程（Ω）”仅用于 2400 自动电阻，不参与 2600 的 V/I 计算。

固定值脉冲以“源值”为峰值、“基线”为间歇电平、“点数”为脉冲次数；扫描脉冲的每个峰值来自生成的扫描数组。脉宽是峰值的目标持续时间，周期是相邻脉冲起点的目标间隔，2600 基线间隔约为周期减去脉宽。2600 采样使用“2600 采样延时”，而非高级直流的“稳定延时”；有测量时每个脉冲返回一组 V/I，不返回完整电气波形。2400/2430 逐点操作中的主机通信会额外影响实际脉冲间隔，不能据目标周期承诺精确整组时序。脉冲完成后才进入后续节点，需要峰值期间曝光时应另行设计相机与源表的硬件触发同步。

窗口结果表使用 V、mA、Ω、W；既有点测/扫描数据库结构与单位不变。测量设置、目标数组、电阻与原始状态保存在独立扩展表 `t_scgd_measure_result_smu_local_details`，按点测/扫描类型及结果 ID 关联。首次保存高级结果时初始化这一张扩展表，需要建表权限；主结果与详情在同一事务保存。普通旧结果查询/写入不要求新列；历史界面在扩展表存在时批量读取详情，保留原生电阻结果。电阻溢出或无效比值显示为空，不用零替代。仅输出不生成虚构的 V/I 或测量数据库记录。源记忆扫描只切换已开放的源值/保护值，不表示完整复刻厂家任意模式分支序列。原始状态是仪器返回字段；2400 为读数状态字，2600 直流为 compliance 标记，2600 脉冲为读数缓冲状态字，不统一解释为同一种位图。

高级节点每次进入执行一组设置，内部扫描/脉冲完成后下游进入一次；放在重复框时每轮可执行一组，不复用旧单点自动合批。节点依然持有整个流程的源表使用权，正常结束按节点选项关闭，失败/取消/超时尝试关闭。脉冲完成后已经返回基线，后续相机节点不会自动与脉冲峰值同步。高级模式期间旧 `SMU.MeasureResult` 读取被拒绝，避免把新回包格式套进旧解析器；执行普通点测会复位相关高级状态后恢复原有读取路径。停止不会中断阻塞中的 SDK 调用，必须等返回后清理，清理失败保留未知状态。

`LocalSmuAdvancedTests` 保护本地 ABI、A/mA 边界、原生 Ω 历史往返、仅输出无伪造读数、会话取消/占用，以及 WPF 节点草稿与流程保存兼容。原生 `SmuLocalProtocolTest` 直接编译生产协议头，使用通信替身检查命令、结果完整性和失败关闭；这些离线验证不覆盖实际脉冲时序、保护、外部接线或 MySQL 迁移验收。

## 手动 MQTT 命令与客户端限制


| 命令 | 实际参数来源和载荷 |
| --- | --- |
| `Open` | `DevName`、`IsNet`，加当前显示 `Channel` |
| `GetData` | 当前源类型与当前参数组，发送 `IsSourceV`、`MeasureValue`、`LimitValue`、`Channel` |
| `Scan` | `Params.DeviceParam` 内的 `IsSourceV`、`BeginValue`、`EndValue`、`LimitValue`、`Points`、调用方指定的 `Channel` |
| `CloseOutput` | 调用这一刻的 `DisplayConfig.Channel`，不是自动绑定到上次点测/扫描通道 |
| `Close` | 关闭设备服务请求；与单通道 `CloseOutput` 不是同一个命令 |

`IsUseLimitSigned` 默认启用。`GetData` / `Scan` 校验失败会返回 `null`，不会发出请求；`IsLimit` 内把电流输入除以 1000 后比较，即这一路电流参数按 mA 换算。现有显式限制仅覆盖 `Keithley_2400`、`Keithley_2600`、`Precise_S100` 分支，其它设备类型直接放行；扫描检查只使用终点和限值，不等于校验了整个扫描区间。不要以关闭此校验作为排障手段，也不要把这些客户端分支当作完整硬件安全规范。

`SetParam()` 虽然返回 `true`，当前只表示已调用发布方法；它没有等待服务成功回包。其它方法返回的 `MsgRecord` 同样只是消息追踪对象。

## 成功回包如何变成结果

`MQTTSMU` 的结果处理筛选订阅主题、设备 Code 和 `Code=0`。公共消息层把匹配 `MsgID` 的成功回包标为 `Success`，不等待下面的数据库读取或视图添加，所以请求成功不等于结果已可展示。

| 回包路径 | 结果关联与更新 |
| --- | --- |
| `GetData` | 要求 `Data.MasterId > 0`，按 ID 从 MySQL 读取 `SMUResultModel`；有记录才新增结果并更新记录所属 A/B 通道读数 |
| 当前通道的 `GetData` | 仅当 `model.ChannelType == DisplayConfig.Channel`，再更新当前投影读数，并将 V/I 同步到现有 `DeviceSpectrum` 的显示配置 |
| `Scan`，`FlowEngineManager.ServiceVersion >= 4.0.2.115` | 要求正数 `MasterId`，从 MySQL 读取 `SmuScanModel` 后新增扫描结果 |
| 更旧版本的 `Scan` | 用回包 `VList` / `IList` 和该实例最近的 `_lastScanParam` 生成临时结果，`Id=-1`；不是已持久化历史记录 |

扫描结果处理不执行点测的通道读数/Spectrum 同步逻辑。旧版本的 `_lastScanParam` 只有一个实例字段，不是按 `MsgID` 保存的扫描参数表；不能据此宣称并发扫描结果已可靠隔离。没有 MasterId、数据库记录缺失或处理异常，都可能造成“回包成功但无结果项”。

## 输出关闭的实际边界

手动点测完成后没有自动 `CloseOutput`。服务模式“关闭输出”按钮发送请求后立刻清空显示 V/I，没有等待关闭成功；本地模式在 SDK 确认成功后才清空对应通道读数。空白读数仍不证明实机输出已关闭。

服务模式手动扫描的 `DisplaySMU.VIScan_Click` 在成功终态后等待约 1 秒，向提交扫描时捕获的通道发 `CloseOutput` 并清空显示，再等待约 1 秒。本地模式由会话在扫描操作内关闭输出，不走此延迟请求。

服务模式失败或超时走非 `Success` 分支，没有自动关闭输出。代码中另有“`Success` 且 `Code!=0` 就关闭”的分支，但公共 `MQTTServiceBase` 已把非零 Code 归为 `Fail`，正常消息入口不能把它当作失败兜底。本地采集异常会尝试关闭该操作的输出，主动关闭连接会等待原生调用返回后释放；SDK 释放失败会报告失败。无响应、报错、取消等待或按钮恢复可用都不是安全断输出的证明；需要按现场规程确认目标通道的实际输出。

## Flow 的独立载荷与完成判据

`SMUNode` 自己持有通道、源/限值和量程。`SMUBaseNode.IsCloseOutput` 默认为 `false`，即未启用正常结束自动关闭输出；启用时，服务模式 `Reset` 延迟发送关闭请求，本地模式直接执行串行关闭，两者使用节点通道。发送了关闭请求或 SDK 返回成功仍不等于实机输出确认。

`SMUSweepModelNode` 的 `Scan` 使用 `SMUSweepParam(模板名, IsCloseOutput)`，不同于手动扫描内联的 `DeviceParam`。不要把手动界面的限值检查、延迟关闭或最近模板字段套到该服务模板节点；流程整体终态见[Flow 执行会话](../workflow/execution.md)。

选择本地后端时，原有流程图无需替换源表节点：现有点测/CSV/模板循环、扫描/模板扫描、结果读取及物理设备打开/关闭/重开节点在进程内执行，不发布 MQTT 请求；可自动打开已配置的本地源表，并使用提交时快照的本地串口波特率。模板取自已加载的 `TemplateSMUParam.Params`，要求 ID 或名称唯一，参数在提交时快照。内联 `DeviceParam` 优先于模板。`SMU.MeasureResult` 读取最近使用通道及源类型，并按节点等待时间延迟结果转交。流程沿用批次、节点 ZIndex 和 `PersistResults`，保存正数结果 ID 后发布现有结果消息。

新建流程可使用“本地设备 → 源表”（`LocalSmuNode`）。它只有普通 `IN` / `OUT`，每次进入执行一次本地 `StepData`：选择节点配置的 A/B 通道和源类型，设置源值、保护限值并完成单点测量，再放行后续节点；不在节点内循环，也不需要 `IN_LP_NEXT` 或循环名称。设备连接、量程及客户端限值检查复用本地源表会话，未连接时可按“自动连接”打开。节点实现位于 `Engine/ColorVision.Engine/FlowProcessing/Nodes/LocalSmuNode.cs`，使用现有点测结果、批次和 `PersistResults` 链路，不发送 MQTT。

属性面板与重复框使用相同的参数名称和单位：电压源显示“设定电压（V）”和“电流上限（mA）”，电流源显示“设定电流（mA）”和“电压上限（V）”；切换源类型时属性面板立即更新。将这个节点放入重复框后，可为这两个参数保存逐轮数组，数组长度等于重复次数，初始值取节点当前配置；数组随流程保存。源类型、通道和量程仍由节点固定配置决定，不参与数组替换。每轮解析后的值形成独立执行快照，日志和设备请求使用同一份快照，不回写节点默认值；进入 SDK 时沿用既有 V/A 换算及手动量程约定。

重复框只包含一个本地源表、执行 2～100000 次且保护上限各轮相同时，会尝试仪器内部快速扫描。等间隔递增数组使用线性扫描，任意跳变、递减或恒定数组使用列表扫描；源类型、A/B 通道及量程沿用节点固定配置。打开后读取原生驱动的扫描能力，仅声明支持对应模式的驱动启用优化；旧 DLL、未支持的机型、变化的保护上限、含多个节点或仅一轮时继续逐轮点测。当前修复后的 Keithley 2600 驱动仅对识别到的受支持 A/B 代型号提供新扫描能力，原始无后缀和未知型号不启用自动批量扫描；A/B 通道选择不代表双通道同步扫描。单节点框全部参数在通电前一起校验，即使回退逐点或列表中间点也不能绕过客户端限制。

整批成功后保留每个点的单点结果，并增加完整扫描曲线；下游只进入一次，`SMUResult` 与 `LocalSmu` 保持最后一个实测点，`LocalSmuScan` 和 `SMUScanResult` 提供完整扫描，后者的 `ScanList` 保留实际请求数组。后续源表节点成功执行普通点测时清除这两个扫描字段，避免把上游旧曲线当成本次扫描。会话与 `LocalSmuScan` 中电流使用 mA，既有扫描回包、曲线存储和视图原始 `IList` 仍使用 A；曲线坐标与右侧逐点表格统一显示 mA，显示转换不改原始数组或存储单位。批量点没有单独硬件时间戳或耗时，采用整批采集完成时间，逐点耗时为 0，整批耗时记录在扫描结果；不伪造逐点采样时间。曲线仅绘制测量数组，不按目标终点补造平台点；视图默认统一使用 V/I 坐标，可显式交换横纵轴，历史记录保留 A/B 通道。节点结束记录的 `ExecutionMode` 区分 `Point`、`LinearScan`、`ListScan`。扫描失败或取消后不重新逐点通电，不发布成功曲线，输出仍按流程失败清理。

源表单点测量完成后继续保持输出，让同一轮后续相机、光谱仪或算法完成工作，换到下一轮时也不先关闭。节点的“流程结束关闭输出”（`CloseOutputOnFinish`）默认开启，在整个流程正常结束时关闭本流程使用的通道；关闭该选项时，正常结束保留输出。相同流程的多个新源表节点共用同一通道时，只要有一个节点要求结束关闭，该通道就会关闭。流程失败、取消或超时均尝试关闭已用通道，不受正常结束保留输出的选项影响；仍需等待正在执行的原生调用返回。关闭失败会将本地状态置为未知并记录错误，成功回包和流程结束都不能替代实际输出状态确认。

新节点从开始使用到流程收尾持有整个本地源表会话的输出使用权，防止在“设置源表 → 相机/光谱仪测量”之间插入其它设置。占用期间，同一会话的手动操作、其它流程及未携带该使用权的旧源表节点会明确提示占用；不要在持有期间混接旧源表读取或设备控制节点。使用权直接归流程资源管理，不作为重复框每轮清除的临时资源；正常收尾后释放，原有本地/服务后端连接互斥与旧流程行为保持原契约。

流程停止或超时后拒绝迟到结果；清理被丢弃结果时检查该次测量的输出归属，不关闭同通道后来开始的测量。SDK 没有可中断接口，超时后的原生调用仍要等返回再完成清理，不能把流程终态当作硬件释放已完成。

“工具 → IV / IVL 实时曲线”左侧可选择并执行、停止主工作区流程，沿用工作流程面板的模板和运行命令；执行中禁用模板切换。右侧随当前批次的节点完成通知更新曲线并列出最近 500 个点，无需配置 IVL 后处理。支持 IV、I-L、V-L、P-L 及电流、电压、亮度的时间趋势，可选择显示系列、导出当前批次显示数据 CSV 和保存图片。批次变化、节点完成及流程最终化时触发后台读取，不使用定时轮询；读取期间新到的节点通知合并为后续补读，每次成功读取即更新曲线。切批次和关闭后拒绝迟到的旧读取结果；关闭窗口只解除订阅，流程继续执行。连接失败保留最近一次成功数据，下一节点通知到达时重试，也可点击“重新读取结果”。

监控要求 MySQL 已连接并启用流程结果保存，仅在结果入库后显示；本地批量扫描必须等仪器返回整批数据，不能展示仪器尚未返回的中间点。电流统一显示为 mA，扫描存储中的 A 只在显示时转换，保留测量顺序以显示往返曲线。时间曲线以批次开始为零点，使用记录时间；没有逐点时钟的扫描数组不绘制时间趋势。相机读取 XYZ POI 的 Y，光谱读取亮度结果，不将光通量/EQE 结果标成亮度。本地算法和普通光谱持久化时保存当前执行上下文的上游 `SMUResult` 关联；显示优先使用记录内的电压、电流及明确的源表结果 ID。旧数据仅在单一源表设备/通道/节点且前一测量时间唯一时按时间匹配，多源或时间歧义时保留亮度时间曲线并提示未配对，不能按当前记录数量猜测。每类最多读取最近 20,000 条记录，扫描最多最近 20 条且合计最多 20,000 点，达到上限时提示截断；CSV 导出受同一显示上限约束。

## 证据与验证缺口
