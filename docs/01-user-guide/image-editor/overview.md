# 图像编辑器概览

图像编辑器是 ColorVision 里最常用的结果查看和交互区域之一。你会在这里查看图像、缩放平移、画 ROI、做标注、播放视频，以及在特定场景下切到 3D 或伪彩色视图。

## 你能在这里做什么

- 查看常见图像结果，并缩放、平移或适配画面
- 画矩形、圆、多边形、曲线和文本标注，并在属性面板调整所选对象
- 使用伪彩色、直方图或 3D 视图观察数据
- 用 Blob / 连通域分析整图或矩形、圆、多边形 ROI，并查看/导出区域表
- 提取整图或 ROI 轮廓，查看层级、面积、周长、质心、圆度、实心度和筛选原因
- 使用水平、垂直或折线卡尺定位亚像素边缘点，或对显式点集拟合直线/圆并导出残差、质量与拒绝原因
- 使用可保存的矩阵 preset 做仿射/透视变换，并查看有效区域 mask 与正逆矩阵诊断
- 以当前图为 reference、另一文件为 moving 做相位相关或 ORB 单应配准，查看配准图、有效区域、矩阵、匹配和质量诊断
- 在视频文件场景下直接播放、暂停、拖动进度和切换预览缩放

## 常见使用顺序

1. 先打开一张图像或一个结果窗口。
2. 用缩放和平移确认关键区域。
3. 需要测量或标记时，再切到绘图工具。
4. 需要看对象参数时，打开属性面板。
5. 如果输入是视频，优先先确认播放是否流畅，再做进一步分析。

## 视频模式会发生什么

当打开的是支持的视频文件时，图像编辑器会切到视频工作模式。此时通常会看到：

- 播放、暂停、进度和倍速控制
- 预览缩放、静音或自动隐藏工具栏选项

如果是高分辨率视频，先降低预览缩放通常比一开始就追求原始分辨率更实用。

## 哪些场景特别常见

### 看检测结果

- 先确认原图和结果覆盖是否对应
- 再看 ROI、标注和属性是否正确

### 调整图像显示

- 优先使用缩放、伪彩色和对比观察
- 不要一开始就修改底层配置，先确认是不是显示问题

### 检查视频或动态数据

- 先验证播放是否正常
- 再决定是否降低预览比例或关闭部分附加显示

### 查找亮区或暗区 Blob

打开“算法调用 → Blob / 连通域”并选择整图或 ROI；设置 0..255 标称阈值、前景、连通性和尺寸筛选。结果表包含面积、边界框、质心、填充率和拒绝原因，绿色框只显示通过项；CSV/JSON 可导出完整结果，关闭窗口会移除临时框且不修改原图。

### 提取和筛选轮廓

打开“算法调用 → 轮廓提取”并选择整图或 ROI；设置阈值、前景、层级、点压缩及几何筛选。青色线显示通过项，结果表和 CSV/JSON 同时保留坐标、层级、测量值以及未通过项的拒绝原因；关闭窗口会移除临时线条且不改动原图。

### 定位亚像素边缘

打开“算法调用 → 亚像素边缘”并选择水平、垂直或折线卡尺组；方向决定极性，参数控制采样、法向平均、平滑与最小梯度。绿色点和青色线分别表示接受的边缘与搜索卡尺，结果表及 CSV/JSON 包含坐标、梯度、质量、不确定度和拒绝原因；需要拟合时再用“算法调用 → 直线拟合”或“圆拟合”选择点集，查看投影、残差、离群原因，以及圆的中心、半径和角覆盖。结果窗口关闭时都会移除临时图形且不修改原图。

### 配准两幅图像

打开“算法 → 图像配准...”；当前图像固定为 reference，再选择要对齐的 moving 文件。纯平移、同尺寸图优先使用 PhaseCorrelation；存在旋转、缩放、透视或尺寸不同且纹理足够时使用 OrbHomography。两幅图必须采用相同位深、通道/像素格式和编码色彩空间，V1 不做隐式转换，也不接受 ROI。结果窗口显示配准图、有效区域 mask、moving→reference 矩阵、匹配点与残差/置信度，可保存 PNG 或导出 CSV/JSON；关闭窗口会移除临时轮廓和点且不修改原图。已知相机标定参数时，可用“算法 → 镜头畸变校正...”输入或加载 Brown-Conrady preset；校正会提交同尺寸原格式图像，并显示有效 mask、输入/输出相机矩阵、系数和标定来源，未提供的标定质量不会被伪造成置信度。需要 Dark/Flat/Shading/Bad-pixel 参考校正时，打开“算法 → 成像校正...”，按固定顺序启用阶段并选择参考图；前三类参考必须与当前图尺寸/格式/色彩编码一致，坏点 map 必须是同尺寸 Gray8。高级参数可设置零值/过曝保护、无效参考、增益、邻域和 float 输出范围；preset、有效 mask、阶段有效比例、参考 SHA-256 及 CSV/JSON 导出用于复现。如果加载参考期间当前图被清空、切换或更新，旧结果不会覆盖新图。要观察周期结构时，打开“算法 → FFT / 频域分析...”：选择窗函数和中心化/显示尺度后查看幅度、功率、径向/方向曲线与峰值表；周期和方向以表格/CSV/JSON 的定量值为准，Gray8 频谱图只是归一化显示，不能直接当原始功率。需要解释窄带周期峰并生成滤波建议时，打开“算法 → 摩尔纹分析...”查看 0..100 证据评分、频域热力图和正负共轭 notch 表；评分只表示周期频谱证据，不证明摩尔纹成因。可选 notch 会生成单通道 Gray32Float 亮度预览供另存，不会自动覆盖当前彩色图；旧“去摩尔纹”仍是兼容图像处理命令，语义不同。

## 常见问题

### 图像显示正常，但操作感觉卡顿

- 先缩小视图或减少同时显示的内容
- 视频场景下先降低预览缩放
- 3D 视图场景下先降低目标分辨率或切回普通视图确认问题范围

### 标注或 ROI 不容易选中

- 先确认当前是否还停留在绘图模式
- 尝试回到选择状态后再点击对象
- 必要时结合 [属性编辑器](../interface/property-editor.md) 查看当前选中对象

### 视频画面不同步或不流畅

- 先暂停后重新播放
- 再尝试拖动进度条跳转
- 对高分辨率视频优先降低预览缩放后复查

### 3D 视图打开后效果异常

- 先确认输入数据本身是否适合做高度或强度可视化
- 再检查是否需要降低目标分辨率或切换颜色映射
