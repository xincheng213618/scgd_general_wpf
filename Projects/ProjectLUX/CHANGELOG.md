# CHANGELOG

## [1.1.5.9] 2026.09.10

1. 新增基于已有聚合记录的结果统计，支持日、周、月及全部周期、SN/判定筛选、通过率、CT 和分页查看；保持 ObjectiveTestResult、检测计算和客户定制导出不变。
2. 接入 ProjectLUX SQLite 表统计、完整备份、历史清理及手动迁移压缩。新增正文使用与 ARVRPro 相同的 GZip BLOB 字段，未迁移的旧 TEXT 仍可读取，保留原图片路径。
3. 压缩正文需要新版插件读取；LUX CT 保持首次保存至最后更新的原有记录口径。本次不涉及现场 MySQL 空图片路径的修复。
4. 最低主程序版本更新为 `1.4.14.18`。

## [1.1.5.8] 2026.09.06

1. 保留原有布局，统一主界面分隔线、编辑图标、流程提示和 Recipe/Fix 窗口的黑白主题配色；清空结果或选择未完成记录后恢复当前主题背景。
2. 结果明细采用主题隔行背景和边框，修复选中行的文字对比度，保留检测判定及图像标记的业务含义。

## [1.1.5.7] 2026.08.27

1. 对齐 ProjectARVRPro 图像保存链路：等待图像加载和结果图层渲染完成后捕获快照，后台保存标记图或原位深原图，并将成功路径持久化到结果数据库。
2. 增加结果图格式、导出尺寸、标记混合、原图格式及 TIFF 压缩配置；原始结果图被清理后可回退显示已保存图像。
3. 增加结果点位名称、详细数据、文字字号和图层自动刷新配置，并将流程管理窗口压缩为 800×600 自适应布局。
