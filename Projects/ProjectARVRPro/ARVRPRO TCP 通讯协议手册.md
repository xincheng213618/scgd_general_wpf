# ARVRPRO TCP 通讯协议手册

完整协议统一维护在 [ARVRPro TCP 通讯协议](../../docs/04-api-reference/projects/project-arvr-pro-protocol.md)，包含初始化、RunAll、流程启用设置、切图确认、AOI 中转、状态码、标准/Legacy 结果和联调条件。

服务端需要加载 ProjectARVRPro，并在 ColorVision 中启用 Json 模式的 Socket Server（默认端口 6666）。协议会推进真实设备测试或修改运行配置，接入时使用与项目包版本对应的仓库文档。

独立客户端与离线样例见 [Integration Demo](../../docs/04-api-reference/projects/project-arvr-pro-integration-demo.md)。
