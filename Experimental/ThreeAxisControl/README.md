# 三轴控制台

独立的 WPF 应用，运行于 Windows x64 和 .NET Framework 4.8。界面支持每显示器 DPI 缩放。PMC100-2 控制 X、Y，MC06-004A 控制 Z。两台控制器可以分别连接。

## 使用

1. 将交付包全部解压，打开 `ThreeAxisControl.exe`。首次启动勾选「模拟模式」，可先连接两台模拟控制器，试用定步移动、位置显示和全部停止。程序已打开时，再次运行会唤起原窗口。
2. 接真机时，先断开模拟连接并取消勾选「模拟模式」。退出占用同一 COM 或 UDP 端口的厂家工具。在「设备设置」填写 XY 的实际 COM 口和波特率，默认 `57600`，串口格式为 `8N1`，无流控。
3. 在「设备设置」填写 Z 的工控机网口 IPv4、控制器 IPv4、本机 UDP 端口及实际轴通道。预填 `192.168.0.200`、`192.168.0.1`、`60000` 和通道 `1`，应按现场配置和接线核对。控制器端 UDP 端口由厂家 SDK 固定为 `60000`。上电后按厂家流程完成机械回零，再使用本程序的相对移动。
4. 连接后单击方向按钮做一次定步移动。位置、步长和软件限位都使用控制器脉冲坐标。设置了移动方向的软限位时，步长会在限位处截断。
5. 勾选「持续运动」后按住方向按钮。该方向已设软限位时向限位移动，留空时按步长逐段移动，控制器报告到位后才发下一段。松开、丢失鼠标捕获、窗口失焦、切到设置页或退出程序都会发起停止。
6. 点击「全部停止」向已连接的控制器分别发出软件停止。现场急停使用独立的硬件回路。首次联调时，先读位置，再用小步长逐轴核对方向、限位与停止。

| 轴 | 正向 `+` | 负向 `−` |
| --- | --- | --- |
| X | 向右 | 向左 |
| Y | 前进 | 后退 |
| Z | 向下 | 向上 |

按现场接线，软件 X 使用 PMC100 的 Y 通道，软件 Y 使用 PMC100 的 X 通道。位置、运动参数和软限位均随各自的实际通道对应。

XY 的初速度、最高速度和加速度使用 PMC100 对应参数的原单位，留空沿用控制器设置。Z 初速度和最高速度以脉冲/秒输入，加速度以脉冲/秒²输入并用于加减速，初速度和加速度可沿用默认值。

程序会恢复 XY 串口和波特率、Z 的两端 IP、本机 UDP 端口与通道，以及三轴各自的步长、速度、加速度和软限位。配置保存在 `%LOCALAPPDATA%\ThreeAxisControl\settings.xml`，同一 Windows 用户换用新版亦可读取。

需要一打开软件就连接真机时，取消勾选「模拟模式」，再在对应控制器区域勾选「启动时连接」。启用后，下次打开会使用已保存的参数连接所选设备。启动时只检查连接和读取状态，移动由操作员发起。

XY 界面的状态只展示串口协议可读取的信息。Z 位置采用 MC06-004A 返回的规划脉冲位置，并显示 SDK 提供的运动、限位及报警状态。Z 首次移动时会按控制器状态使能轴。现场接线、比例和行程以设备调试结果为准。

XY 报错时，可以点击「复制记录」获取实际发出的指令和已经收到、但程序未识别的回复。显示「超时，未收到回复」时，请一并提供控制器面板的型号和固件版本。

## 构建

在项目目录执行 `dotnet build .\ThreeAxisControl.csproj -c Release`。构建需要 .NET Framework 4.8 Developer Pack。真机 Z 轴需要从用户提供的 `Z轴.rar` 内层控制卡资料中取 `64位动态库\GAS.dll`，放在应用 EXE 同目录。XY 和模拟模式可直接运行。

## 资料

- `XY.rar` 中的 `PMC100-3二次开发指令说明.pdf` 和 `PMC100.cs` 提供串口指令与示例。目标型号 PMC100-2 的回复行为需现场验证。
- `Z轴.rar` 中的操作手册、`GAS_N.h`、C# 示例及 64 位 `GAS.dll` 提供 MC06-004A 接线、通信和运动接口。
